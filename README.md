# USAFA Team Handball — Team Site + Stat Tracker

**index.html** is the whole site, one self-contained page: a public welcome page,
the team baseball-card roster, and the season dashboard — plus, behind the admin
wall, live game stat tracking with a tap-on-goal shot map and a full Excel
workbook exported per game. Built mobile-first; works offline once loaded.

Live at **https://rwgthefour.github.io/Handball/** — every push redeploys it.

## How data flows (GitHub is the store)
- `games/*.xlsx` — game workbooks committed here **load automatically for every
  visitor** (season record, player totals, charts, zero clicks). After a game,
  add the exported workbook to this folder — the GitHub app/web "Upload files"
  from a phone works; no other step needed. `games/index.json` is a manifest
  regenerated by the build; the site also asks the GitHub API, so a web-UI
  upload shows up even before the manifest catches up.
- `data/roster.xlsx` — the stat roster a first-time device starts from.
- `photos/` — team portraits. Filename (lowercase, no extension) must match a
  card's photo key in `src/part_core.js` (`cavanaugh`, `tierney`, …); run the
  build to embed. Cards show a crest placeholder until then.
- Nothing a visitor does uploads anywhere; live tracking saves in that browser
  and moves as Excel files.

## Admin
Game tracking, the stat-roster manager, imports and stored-game management sit
behind ☰ → ADMIN SIGN IN. The password is deliberately in the public source —
it is a courtesy gate for a sports site, not a vault.

## Editing
The page is generated — never hand-edit index.html.
1. Edit `src/part_head.html` (markup/CSS), `src/part_core.js` (engine +
   TEAM_PAGE cards), `src/part_xlsx.js` (Excel + repo data), `src/part_charts.js`.
2. `python3 src/build.py` — rewrites index.html, embeds photos, refreshes the
   games manifest.
3. Verify (96 end-to-end assertions in real Chrome, including the Excel round
   trip, the admin wall, the hosted data flow and a phone-size pass):
   `python3 -m http.server 8123 --bind 127.0.0.1 &` in the repo root, then
   `node src/probe_handball.js`, then kill the server. Uses the Playwright
   install from the ApolloDagger repo on this machine.

Events are the single source of truth, keyed by stable player id (pid), never
jersey number. SheetJS (Apache-2.0) is embedded from `src/xlsx.full.min.js`.
